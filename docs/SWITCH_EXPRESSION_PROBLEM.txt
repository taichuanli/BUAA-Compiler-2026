文法修改
课下的 switch 语句保持不变，另外新增 switch 表达式：分支用 -> 引导，分支体是一个表达式后跟分号。

修改文法如下：

// 新增：表达式形式的 switch
基本表达式 PrimaryExp → '(' Exp ')' | LVal | Number | SwitchExp

Switch 表达式 SwitchExp → 'switch' '(' Exp ')' '{' { SwitchArm } '}'

分支 SwitchArm → 'case' Number '->' Exp ';'
               | 'default' '->' Exp ';'
按位置区分两种形式：语句位置的 switch 一律按语句形式分析，表达式位置的 switch 一律按表达式形式分析。两者的分支分隔符不同（: 与 ->），不会互相匹配。

分支体只有一种写法：一个表达式后跟 ;，分支里不能再写声明或语句序列。

每个 case 只跟一个常量，default 单独成支。

-> 是新记号，不新增关键字。

新增错误处理
出错位置	类别码	报错行号（缺失符号前一个终结符所在行）
分支值后的 ; 缺失	i	该值 Exp 的末尾
表达式分支缺 ->	o	最后一个标签常量所在行；default 取关键字所在行
switch ( Exp 的 ) 缺失	j	条件 Exp 的末尾
注意：新增错误类型 o，表示“缺少分支分隔符 ->”。报错行号取该分隔符前一个终结符所在行；报错后把缺失的 -> 当作已经存在继续分析，不要吞掉下一个单词。语句形式 case / default 后的 : 与课下一致，本卷不检查。

注意事项
本题目只需考虑词法和语法分析，无需考虑语义正确性分析。

本题目中对于每个错误样例，只会出现词法分析和语法分析阶段的错误，包括本卷新增的错误类别 o。

注意样例中可能出现涉及新文法的错误。

语句位置的 switch 一律按语句形式分析，因此表达式形式的 switch 不能直接作为一个独立语句使用，它必须出现在其他表达式内部。

        case 3 -> 30;
        default -> 0;
    };
